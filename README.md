# Early Warning System for Student Academic Performance

A mini-project built with Python and scikit-learn using the UCI Student Performance dataset to classify students into At Risk, Average, and Good academic categories.

# Models & Results
- Decision Tree Classifier: 46.15% accuracy
- Random Forest Classifier: 63.08% accuracy (stronger overall precision and accuracy; 'absences' was the top feature)
